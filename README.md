# FixIt 🔧 — متجر قطع غيار BMW & MINI

موقع متكامل لبيع قطع غيار BMW وميني كوبر (جديد ومستعمل وارد)، جاهز للنشر على Vercel.

## ✨ المميزات

- **موقع ثنائي اللغة (عربي/إنجليزي)** بزرار تبديل في الهيدر — الاتجاه والأسعار وأسماء المنتجات بتتغير تلقائياً
- **تصميم فاتح عصري** بهوية FixIt البرتقالية، متجاوب مع الموبايل
- **متجر بفلاتر وترقيم صفحات**: الماركة، الموديل (F30, E90...)، الفئة، الحالة (جديد/مستعمل)، بحث برقم OEM، ترتيب بالسعر/الأكثر مبيعاً/الأعلى تقييماً
- **بحث فوري في الهيدر** باقتراحات لحظية زي المتاجر العالمية
- **حسابات عملاء** (`/account.html`): تسجيل/دخول برقم الموبايل + "طلباتي" لمتابعة كل الطلبات
- **تقييمات ومراجعات** ⭐ على كل منتج مع شارة "عميل مسجّل"
- **مفضلة** ❤️ و**شاهدتها مؤخراً** و**معرض صور** لكل منتج
- **كوبونات خصم** 🎟️ (نسبة أو مبلغ ثابت بحد أدنى للطلب) تُنشأ من لوحة التحكم
- **طرق دفع متعددة**: عند الاستلام / انستاباي / فودافون كاش — مع تعليمات تحويل تلقائية
- **تتبع الطلب** (`/track.html`): برقم الطلب + الموبايل، بخط زمني (استلمنا → تأكيد → شحن → تسليم)
- **لوحة تحكم** (`/admin.html`): نظرة عامة بإحصائيات المبيعات والأكثر مبيعاً وتنبيه المخزون المنخفض + إدارة المنتجات والطلبات والكوبونات والعملاء
- **صفحة سياسات** (`/policies.html`): الشحن والاسترجاع والضمان
- **مزامنة مخزون** (`/api/sync`): جاهزة للربط مع أي نظام خارجي — لو قطعة اتباعت هناك تتخصم هنا تلقائياً
- **اسأل الخبير** (`/assistant.html`): مساعد ذكي يشخّص المشكلة ويقترح القطعة

## 🚀 النشر على Vercel

المشروع جاهز — اربط الريبو بـ Vercel وهيشتغل مباشرة. بعدها أضِف متغيرات البيئة دي من
**Settings → Environment Variables**:

| المتغير | الوظيفة | مطلوب؟ |
|---|---|---|
| `ADMIN_TOKEN` | كلمة سر لوحة التحكم `/admin.html` | ✅ لتفعيل اللوحة |
| `AUTH_SECRET` | مفتاح توقيع جلسات حسابات العملاء (أي نص عشوائي طويل) | ✅ للإنتاج |
| `SYNC_SECRET` | رمز سري لربط المخزون مع نظام خارجي | عند الربط |
| `UPSTASH_REDIS_REST_URL` + `UPSTASH_REDIS_REST_TOKEN` | حفظ دائم للمنتجات والطلبات (مجاني من [upstash.com](https://upstash.com)) | ✅ للإنتاج |
| `OPENAI_KEY` | تشغيل "اسأل الخبير" | اختياري |
| `MOUSSTEC_WEBHOOK_URL` + `MOUSSTEC_SECRET` | إرسال طلبات الموقع لسيستم Mouss Tec كفواتير مسودة | عند ربط موس تك |
| `PAYMOB_API_KEY` + `PAYMOB_INTEGRATION_ID` + `PAYMOB_IFRAME_ID` + `PAYMOB_HMAC_SECRET` | الدفع أونلاين بالبطاقة (فيزا/ماستركارد) عبر Paymob | عند تفعيل الدفع بالكارت |

> ⚠️ **مهم**: من غير Upstash، البيانات بتتخزن مؤقتاً في الذاكرة وبترجع للبيانات التجريبية
> مع كل نشر جديد. إنشاء قاعدة Upstash مجانية بياخد دقيقتين، وانسخ منها المتغيرين المذكورين.

## 🤝 الربط الجاهز مع سيستم Mouss Tec

الموقع متكامل مع [Mouss Tec ERP](https://github.com/saeedmohamed248-dev/mousstec) — المخزون واحد في الاتجاهين:

- أي حركة مخزون في موس تك بتحدّث الموقع فوراً
- طلبات الموقع بتتسجل في موس تك كفواتير مسودة تلقائياً
- `python manage.py fixit_sync_all` في موس تك يرفع الكتالوج كله للموقع
- التفاصيل الكاملة في ملف `FIXIT_INTEGRATION.md` جوه ريبو موس تك

## 🔄 ربط المخزون مع أي نظام خارجي آخر

الفكرة: الـ **SKU** لازم يكون موحّد في النظامين، وأي بيع في نظام يبلّغ التاني.

**1) لما قطعة تتباع في النظام الخارجي** → يبعت طلب هنا فيتخصم المخزون:

```
POST https://fixitauto.parts/api/sync?secret=YOUR_SECRET
Content-Type: application/json

{ "sku": "BP-34116850568", "quantity": 1 }
```

**2) ربط شوبيفاي مباشرة**: من Settings → Notifications → Webhooks أضِف webhook
لحدث **Order creation** على نفس الرابط أعلاه — أي أوردر في شوبيفاي هيخصم الكمية هنا تلقائياً.

**3) النظام الخارجي يسحب المخزون الحالي**:

```
GET https://fixitauto.parts/api/sync?secret=YOUR_SECRET
```

**4) البيع من الموقع نفسه** بيخصم المخزون تلقائياً، وكل الطلبات بتظهر في لوحة التحكم.
