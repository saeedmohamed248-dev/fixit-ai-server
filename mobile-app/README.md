# 📱 تطبيق FixIt — أندرويد & iOS (Native)

تطبيق حقيقي مبني بـ **React Native + Expo** (مش موقع متغلّف) — نفس الكود بيطلع أندرويد و iOS.
بيسحب كل البيانات من نفس سيرفر الموقع `https://www.fixitauto.parts/api` — أي منتج أو سعر أو مخزون
بتعدّله من لوحة التحكم أو من مزامنة موس تك بيظهر في التطبيق على طول، من غير تحديث للتطبيق.

## ✨ اللي في التطبيق

| الشاشة | فيها إيه |
|---|---|
| **الرئيسية** | بحث، «عربيتي» (اختار الشاسيه)، الأقسام، مختارات FixIt، عروض، الأكثر مبيعاً، وصل حديثاً، مستعمل وارد، شاهدتها مؤخراً، اسأل الخبير، واتساب |
| **المتجر** | فلاتر (القسم، الماركة، الحالة، الموديل/الشاسيه)، ترتيب، تحميل تدريجي، سحب للتحديث |
| **البحث** | البحث الذكي بتاع السيرفر (بيفهم العربي والجمع والمرادفات وأرقام OEM)، القطع الخلصانة بزرار «اطلبها»، سجل البحث |
| **المنتج** | معرض صور، السعر والخصم، المخزون، «بتركب على عربيتك»، اختيار البارت نمبر، الضمان، التقييمات وكتابة تقييم، قطع مشابهة، مشاركة، مفضلة، سؤال واتساب |
| **السلة** | تعديل الكمية (بحد المخزون)، كوبون خصم بيتأكد من السيرفر، شريط الشحن المجاني |
| **إتمام الطلب** | بيانات التوصيل (بتتحفظ للمرة الجاية)، انستاباي / فودافون كاش / عربون (حسب إعدادات اللوحة)، استخدام النقاط |
| **نجاح الطلب** | رقم الطلب، رقم التحويل بزرار نسخ، إرسال صورة التحويل واتساب، تتبع |
| **حسابي** | دخول/تسجيل برقم الموبايل، طلباتي، النقاط والرصيد، تعديل البيانات وكلمة السر، **حذف الحساب** (شرط أبل وجوجل) |
| **تانية** | تتبع الطلب + طلب إرجاع، المفضلة، اسأل الخبير (ذكاء اصطناعي)، اطلب قطعة مش موجودة، عربي/إنجليزي (RTL/LTR) |

الطلبات اللي بتيجي من التطبيق بتوصل لوحة التحكم عادي، ومكتوب في ملاحظاتها `📱 App`.

> ⚠️ **حذف الحساب** محتاج نسخة السيرفر اللي في نفس الفرع ده (`api/_lib/routes/auth.js` — action جديد `delete_account`).
> اعمل Merge للفرع على Vercel قبل ما ترفع التطبيق على المتاجر.

## 🧪 التشغيل والتجربة

```bash
cd mobile-app
npm install
npx expo start          # امسح الـ QR بتطبيق Expo Go أو development build
npm run typecheck       # فحص الكود
```

## 📦 البناء والنشر (من غير Mac ولا Android Studio) — EAS

```bash
npm i -g eas-cli
eas login                                  # حساب Expo مجاني من expo.dev
eas init                                   # يربط المشروع بحسابك (مرة واحدة)

# 🤖 APK للتجربة على أي موبايل أندرويد
eas build -p android --profile preview

# 🚀 نسخ المتاجر
eas build -p android --profile production  # ملف .aab لجوجل بلاي
eas build -p ios --profile production      # بيطلب منك تسجيل دخول Apple Developer وبيعمل الشهادات لوحده
eas submit -p android                      # رفع على Google Play
eas submit -p ios                          # رفع على App Store Connect / TestFlight
```

الحسابات المطلوبة: **Google Play Console** (25$ مرة واحدة) و **Apple Developer** (99$ في السنة).

## 🗂️ تنظيم الكود

```
src/app/            الشاشات (Expo Router — كل ملف = شاشة)
  (tabs)/           الرئيسية، المتجر، السلة، حسابي
  product/[id].tsx  صفحة المنتج
src/components/     مكوّنات الواجهة (كروت، أزرار، حقول...)
src/lib/            الـ API، الحالة (السلة/الحساب/...)، الترجمة، الألوان
assets/             الأيقونة وشاشة البداية
```
